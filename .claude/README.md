# ‏`.claude/settings.json` — מה כאן ומה **לא**

הקובץ רושם את שני ה-hooks ומכיל את חסימות ה-Bash שנכונות בכל פרויקט.

**מה שאינו כאן, במכוון:** נתיבים ספציפיים לאתר — כתובת מעבדה, שם
קובץ מפתח, ‏`Read()` על קובץ מסוים. אלה שונים בכל התקנה, ולכן:

- לשומר `guard-bash.py` — דרך `OTOGIT_SITE_DENY`, שורה לכל דפוס
  בפורמט `regex|נימוק`. הגדרה שבורה **עוצרת את השומר** (קוד 2),
  היא אינה מדולגת בשקט.
- לחסימות `Read()`/`Edit()` — בהגדרות המשתמש המקומיות, לא בריפו.
