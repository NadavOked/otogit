# מדיניות הרשאות — מי מאשר מה, לפי מצב

הקובץ הזה הוא **החוקה** של הצי. סוכן שלא בטוח — עוצר, לא מנחש.

## שלוש רמות, לפי מי ער

| פעולה | סוכן לבד (קלוד כבוי) | עם קלוד | רק הבעלים |
|---|---|---|---|
| סקירת PR (תגובה בלבד) | ✅ | ✅ | |
| דוח בוקר / דיווח ללוח | ✅ | ✅ | |
| רעיון → Issue (‏needs:triage) | ✅ | ✅ | |
| עבודה על Issue עם **‏`agent:ready` + `agent:solo-ok`** → ‏PR | ✅ | ✅ | |
| עבודה על `agent:ready` **בלי** `solo-ok` (קוד server/agent/boot) | ❌ | ✅ | |
| ריצה על מעבדת ה-VM | ❌ | ✅ | |
| פתיחת Issue מבוסס-ראיה / סגירת Issue | ❌ | ✅ | |
| ‏`--amend` + force-push על ענף לא-נסקר | ❌ | ✅ | |
| **מיזוג · פריסה · ייצור · סודות · מחיקת תג** | ❌ | ❌ | ✅ |

## ההיגיון

**‏`agent:solo-ok`** מסמן משימה ש-**‏CI לבדו מאמת אותה במלואה**: מסמכים,
‏workflows, כלי `tools/`. קוד ליבה (`server/` `agent/` `boot/`) דורש
טסטים על מעבדת ה-VM ובקרה שלילית מוכחת — ואת זה סוכן חסר-מעבדה אינו
יכול לספק, ולכן בלי קלוד הוא **לא נוגע**, גם אם המשימה "נראית קלה".

את שתי התוויות ביחד שם רק מי שמוסמך לכך: הבעלים, או קלוד אחרי בדיקה.
**סוכן לעולם אינו מסמן `solo-ok` לעצמו.**

‏PR שנפתח בלי קלוד חייב לשאת בגוף: `נוצר ללא מתאם — אימות: CI בלבד`.

## מה שדורש את הבעלים — עובר דרך שרשור ההכרעות

כל פעולה בעמודת "רק הבעלים", וכל שאלה שסוכן אינו מוסמך להכריע בה — **לא
נשארת בטרנסקריפט ולא ממתינה בשקט**: הסוכן פותח שאלה ממוספרת בשרשור
שרשור ההכרעות של הפרויקט (`discussions.decisions` ב-‏`~/.otogit.json`)
עם המלצה מוצעת, ומסמן מה חסום עד התשובה. **תשובת הבעלים שם היא הכרעה
מחייבת**, והסוכן שפתח מיישם ומתעד אותה ב-Issue.

## מכסות — סוכן שנגמר לו התקציב מכבה את עצמו

לכל ספק יש מכסה, והכלל אחד: **הודעת מכסה בפלט = קירור עצמי** (רישום
`cooldown_until` בקובץ המצב) **והתעוררות אוטומטית** כשהקירור פג — אין
צורך להדליק ידנית אחרי איפוס.

| ספק | זיהוי | קירור עד |
|---|---|---|
| ‏Gemini (חינמי) | ‏HTTP 429 / `RESOURCE_EXHAUSTED` | האיפוס היומי — חצות שעון האוקיינוס השקט (‏~10:00 בישראל) |
| ‏Codex (מנוי) | הודעת usage-limit | ‏5 שעות (החלון), או יממה על תקרה שבועית |
| ‏Grok (מנוי, עד 20/09) | הודעת limit בפלט | ‏6 שעות + ניסיון-גישוש (האיפוס לא פורסם) |

‏`agents-ctl.ps1 list` מציג קירור פעיל (❄️) לצד המתג הידני — שני דברים
שונים: מתג = החלטת הבעלים; קירור = מציאות זמנית של הספק.

**כשל שאינו מכסה נשאר כשל** — ‏429 מקרר; ‏500 של הספק או פלט ריק הם
שגיאה רועשת, לא קירור. אסור לקפל את שניהם לאחד (עיקרון 5).

## צירופים — מה מותר לבד, ומה רק בזוג

הכלל המרכזי: **המוצא אינו המאמת, והמאמת אינו הממזג.** שלושה כובעים,
לעולם לא אותו סוכן בשניים מהם על אותו ממצא.

| פעולה | לבד | הצירוף הנדרש |
|---|---|---|
| סקירה, דיווח, שאלה בשרשור ההכרעות | ✅ כל סוכן | — |
| ‏PR על משימת `solo-ok` | ✅ | ‏CI הוא המאמת |
| **תיקון לפי ממצא של סוקר** | ❌ | סוכן **אחר** (או קלוד) מאמת את הממצא מול הקוד קודם — הסוקרים כבר טעו כאן פעמיים בממצאים "קריטיים" |
| פסיקת "מופרך" על ממצא | ❌ | המאמת חייב להיות שונה מהמוצא, עם ראיה מהקוד |
| קוד ליבה (server/agent/boot) | ❌ | קלוד + מעבדת ה-VM + בקרה שלילית |
| סימון `agent:solo-ok` | ❌ | הבעלים או קלוד — **לעולם לא הסוכן לעצמו** |
| מיזוג · פריסה · סודות | ❌ | הבעלים בלבד |

## מתגים

‏`tools/agents/agents-ctl.ps1` — ‏on/off לכל סוכן, כולל קלוד (`claude`
עוצר את הלולאה שלו באיטרציה הבאה). הרץ המתוזמן מכבד `runner` ו-`grok`/
`codex`; ‏workflows של GitHub נשלטים ב-`gh workflow enable/disable`.
